# SaaS Health

SaaS Health vervangt Module Health.

Het scherm checkt:
- core readiness
- database/schema status
- template loader
- field library
- form templates
- ACF beschikbaarheid
- service-configuratie
- form usages per service

Bij een verse installatie zijn er nog geen services. Dat is geen fout; SaaS Health toont dit als informatieve status.
