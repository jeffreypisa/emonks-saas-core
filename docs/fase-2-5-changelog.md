# Changelog

## Config-first SaaS basis

- Module registry uit de runtime gehaald.
- Module Health vervangen door SaaS Health.
- Admin menu opgeschoond naar Setup, Services, Fields, Forms, Features, Plans, Billing, Workspaces, SaaS Health, Logs en Settings.
- Service defaults voor guestbook/client portal verwijderd.
- Field Library toegevoegd als centrale veldbron.
- Form Templates toegevoegd als vervanging voor form_schemas.
- Services gebruiken form_usages in plaats van inline fields.
- ACF group opties worden als labels beschikbaar gemaakt.
- Workspace service data wordt via resolved service forms verzameld.
