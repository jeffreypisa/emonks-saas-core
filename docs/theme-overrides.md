# Theme Overrides

## Labels
Gebruik `emonks_saas_labels` om frontend labels te bepalen.

## Routes
Gebruik `emonks_saas_routes` om URL segmenten te hernoemen.

## Templates
TemplateLoader zoekt:
1. Actief theme: `/templates/...`
2. Plugin fallback: `/templates/...`

## UX fallback
Plugin fallback templates bevatten nu uitgebreidere UX (feedback, status badges, hints), maar theme blijft leidend.
